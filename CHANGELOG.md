# Design changes

Proposed changes to the Savvy admin dashboard design. Not released yet.

- **Game modes is now Bundles.** A bundle is the prize setup a new stream starts from: points per round, the showdown and its prize, rewards and messaging. There are three: Cash game · Super Savvy Showdown, Sparks game · Savvy Showdown, Cash game · Savvy Showdown.
- **Bundles have no host or sponsor.** Both are picked on the stream; the host also on each time slot.
- **New page: How to play & format.** The "In the app" settings (logo, title, description, power-ups, home screen pill) moved here from Game modes, one card each for Savvy TextChain and Savvy SubText.
- **The format is picked per stream.** TextChain or SubText is chosen on the stream page, in New stream, or in Fill month. A stream without one shows no game icon.
- **A word set is only words.** No game, logo, filter, rewards or showdown prize. Any set fits any stream; rewards and the prize come from the stream's bundle.
- **Time slots are simpler:** time, days, host, and who can join. No game mode.
- **Fill month only creates streams.** It picks one bundle and an optional format for all of them; the word set switches are gone.
- **Bundle messaging shows the library's presets.** Pick one per kind, or open a preset in a side sheet to edit it there.
- **Unsaved changes ask before leaving.** On pages and when closing a side sheet.
